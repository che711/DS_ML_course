## <font color="green">**DS_ML_course**</font>
# DS & ML Course 📊🤖

This repository contains materials, experiments, and projects related to **Data Science** and **Machine Learning**.
It is structured as a hands-on learning path covering fundamental concepts, practical implementations, and real-world use cases.

---

## 📦 Repository Overview

The repository is organized into modules, each focusing on a specific topic:

| Module                | Description                              |
| --------------------- | ---------------------------------------- |
| `01-python-basics`    | Python fundamentals for data analysis    |
| `02-data-analysis`    | Data cleaning, preprocessing, and EDA    |
| `03-visualization`    | Data visualization techniques            |
| `04-statistics`       | Core statistics for Data Science         |
| `05-machine-learning` | Classical ML algorithms                  |
| `06-deep-learning`    | Neural networks and deep learning basics |
| `07-projects`         | Practical end-to-end projects            |

---

## 🧠 Learning Goals

* Build strong foundations in Data Science
* Understand data preprocessing and feature engineering
* Learn statistical thinking for data analysis
* Implement machine learning models from scratch and with libraries
* Work on real-world datasets and problems

## 🚀 Getting Started

### 1. Clone the repository

```bash id="3n2k5p"
git clone https://github.com/che711/DS_ML_course.git
cd DS_ML_course
```

### 2. Create virtual environment

```bash id="7k1zpd"
python3 -m venv venv
source venv/bin/activate  # Linux / macOS
# venv\Scripts\activate   # Windows
```

### 3. Install dependencies

```bash id="4w9x2m"
pip install -r requirements.txt
```

### 4. Run notebooks

```bash id="5c8v1q"
jupyter notebook
```
